# Multi-Region Disaster Recovery Architecture Simulation for Payment System

## Project Overview

This project simulates a highly available payment system architecture using DevOps tools and practices. The objective is to demonstrate disaster recovery concepts, application containerization, CI/CD automation, and monitoring.

## Technologies Used

* Python Flask
* Docker
* Git & GitHub
* GitHub Actions
* Prometheus
* Grafana

## Project Components

### Application Layer

A Flask-based payment application that simulates payment processing requests.

### Containerization

The application is packaged using Docker and deployed as a container.

### CI/CD Pipeline

GitHub Actions automatically validates the application whenever code is pushed to the repository.

### Monitoring

Prometheus collects application metrics and Grafana provides dashboard visualization.

## Benefits

* High Availability Simulation
* Faster Deployment Process
* Automated Validation
* Centralized Monitoring
* DevOps Best Practices
